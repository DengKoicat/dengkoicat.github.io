Token Embedding#

词嵌入维度 (Hidden Size) $12288$ dims
词表大小 (Vocabulary Size) $50257$ tokens
权重矩阵 (Embedding Matrix) $[50257,12288]$

$$\text{参数量} = 50,257 \times 12,288 \approx 6.17 \text{ 亿}$$

如，输入 “I Love You” 在 GPT-3 词表中，对应的Token ID是，

  • "I" $\rightarrow$ ID: 101

  • "Love" $\rightarrow$ ID: 520

  • "You" $\rightarrow$ ID: 1314 将这三个 Token 的 Embedding 拼接得到

    \[3,12288\]

    作为下游 Transformer Blocks 的输入

但是 GPT-3 由于 $O(N^2)$ 的 Self-Attention，一次只能处理 2048 个Token，超出直接报错。

早期可以通过滑动窗口（Sliding Window）解决这个问题，分批处理长文本，但每次重叠部分都 要重新计算。

现代模型的处理：不再切片。直接利用 RoPE 外推 与 FlashAttention 算子优化，在物理上将单次计算窗口扩大至 128k ~ 2M，实现全文本的一次性全局无损注意力计算

Transformer Decoder Blocks#

GPT-3 由 $96$ 层 Transformer Decoder Block 堆叠而成。

  1. LayerNorm
  2. Masked Multi-Head Self-Attention
  3. Residual Connection
  4. LayerNorm
  5. FFN / MLP
  6. Residual Connection 一层Block为， $$X' = X + \text{MHA}(\text{LN}(X))$$ $$Y = X' + \text{MLP}(\text{LN}(X'))$$

如，“一个失败的man”（举例Qwen词表），划分为三个 Token

  • 一个

  • 失败的

  • man Token Embedding，

    $$ X = (一个,失败的,man) \in [3,12288]$$

Position Embedding#

这样也只是将 Token -> 高维空间，为了让模型感知 Token 之间的先后顺序，必须引入位置编码：

  • GPT-3 / BERT（可学习的绝对位置编码）： 死板地在内部初始化一个固定尺寸的座位表矩阵。
  • GPT-3 实现：self.position_embeddings = nn.Embedding(2048, 12288)。 物理锁死窗口大小，完全不具备长文本外推能力，超出 2048 范围直接报错。
  • T5 / Transformer-XL（相对位置编码）： 不关心绝对坐标，只关心两个词之间的相对距离。 计算极其复杂，需要动态修改注意力得分（Attention Score）矩阵，难以在现代大规模分布式并行训练中进行硬件加速。
  • RoPE (旋转位置编码 - 现代大模型标配)： 完美将“绝对位置的形式”与“相对位置的优雅”在数学上统一了起来。通过复数空间旋转向量的夹角，让模型既知道绝对位置，又能天然感受到相对距离。与 FlashAttention 天生绝配。

GPT-3 编码，Position Embedding 为 $P \in [2048,12288]$ 随机初始化 ，

self.position_embeddings = nn.Embedding(2048, 12288)

  • 一个 1

  • 失败的 2

  • man 3
    Token Embedding + Position Embedding ，

    $$\tilde{X} = X+P_{0:3} = (一个,失败的,man) \in [3,12288]$$

    并且归一化,

    $$\tilde{X} = LN(X+P_{0:3})$$

Q K V#

# 输入是 12288 维，输出也是 12288 维
self.W_q = nn.Linear(12288, 12288, bias=False)
self.W_k = nn.Linear(12288, 12288, bias=False)
self.W_v = nn.Linear(12288, 12288, bias=False)

$Q (Query)$ “我想去寻找什么？”（当前 Token 主动去试探别人的特征）

$$Q = \tilde{X} \times \mathbf{W}_q \quad \rightarrow \quad [3, 12288] \times [12288, 12288] = [3, 12288]$$

$K (Key)$：“我能提供什么？”（当前 Token 留给别人来试探的标签）

$$K = \tilde{X} \times \mathbf{W}_k \quad \rightarrow \quad [3, 12288] \times [12288, 12288] = [3, 12288]$$

$V (Value)$：“我本身的实际内容是什么？”（一旦对齐成功，实际要贡献出来的语义信息）

$$V = \tilde{X} \times \mathbf{W}_v \quad \rightarrow \quad [3, 12288] \times [12288, 12288] = [3, 12288]$$

可以这样理解，当 $Q_i$ 与 $K_i$ 相似时，就说明 $K_i$ 就是 $Q_i$ 关注的Question，而 $V_i$ 就是 Answer

  • $\mathbf{W}_q$ 矩阵总参数：$12288 \times 12288 \approx 1.51 \text{ 亿}$
  • $\mathbf{W}_k$ 矩阵总参数：$12288 \times 12288 \approx 1.51 \text{ 亿}$
  • $\mathbf{W}_v$ 矩阵总参数：$12288 \times 12288 \approx 1.51 \text{ 亿}$
一个 (K0​)失败的 (K1​)man (K2​)
一个 ($Q_0$)$Q_0 \cdot K_0$$Q_0 \cdot K_1$$Q_0 \cdot K_2$
失败的 ($Q_1$)$Q_1 \cdot K_0$$Q_1 \cdot K_1$$Q_1 \cdot K_2$
man ($Q_2$)$Q_2 \cdot K_0$$Q_2 \cdot K_1$$Q_2 \cdot K_2$

因为 GPT-3 是 Decoder-only 架构，前文不能偷看后文。因此，在算完上面的点积后，矩阵的右上角（即前文查询后文的位置）会被无情地填上 $-\infty$

  1. 由于 $Q_0$ 只能看到 $K_0$
  2. 模型通过 $Q_1 \cdot K_0$ 建立了“一个 $\rightarrow$ 失败的”这种修饰与被修饰的组合语境。
  3. 网络发现它们的语义极其契合（“什么样的man？$\rightarrow$ 失败的man”）。因此，$Q_2 \cdot K_1$ 会斩获极高的得分。
一个 (K0​)失败的 (K1​)man (K2​)
一个 ($Q_0$)$Q_0 \cdot K_0$$-\infty$$-\infty$
失败的 ($Q_1$)$Q_1 \cdot K_0$$Q_1 \cdot K_1$$-\infty$
man ($Q_2$)$Q_2 \cdot K_0$$Q_2 \cdot K_1$$Q_2 \cdot K_2$

但此时有一个问题 $Q_i \cdot K_j \in (-\infty,+\infty)$ 代表分数，Token 间的关联程度，可以是任何实数
数值不能是任何实数，而是一个概率，满足 $Q_i \cdot K_j \in (0,1)$，且 $\sum_{j=0}^{i} Q_i \cdot K_j^T = 1$
如何实现呢？当然是 Softmax ，

$$\text{softmax}\left(\frac{Q_i \cdot K_j}{\sqrt{d_k}}\right)$$

好了介绍了 $Q_i$ 找到对应的信息 $K_j$ 然后呢？就像找到了对应的冰箱，但里面的东西还等着我们去拿，通过前面的计算我们手上已经有了一个形状为 $[3, 3]$ 的最终概率矩阵，我们把它记为 $A$Attention Weights，以最后一行 $man (Q_2)$ softmax 后举例，

  • 0号冰箱（"一个"）：0.1

  • 1号冰箱（"失败的"）：0.6

  • 2号冰箱（"man"）：0.3 此时，每个冰箱里放着的“真正干货”，就是我们最早通过 $V = \tilde{E} \times \mathbf{W}_v$ 算出来的 $V$ 矩阵（形状 $[3, 12288]$）,

  • $V_0$："一个" 的真正内容

  • $V_1$："失败的" 的真正内容

  • $V_2$："man" 的真正内容

模型拿着那串 $[0.1, 0.6, 0.3]$ 的概率，开始去 $V$ 矩阵里打包提取特征。数学上的操作是行乘以向量的加权求和：

$$\text{"man" 的新向量} = 0.1 \times V_0 + 0.6 \times V_1 + 0.3 \times V_2$$

这就是大名鼎鼎的 Attention Pattern，

$$\text{Attention(Q,K,V)} = \text{softmax}\left(\frac{Q \cdot K^{T}}{\sqrt{d_k}}\right)V$$

Multi-Head Attention#

上面为了方便理解，把 $12288$ 维当成一个整体讲，但真实大模型一般使用 Multi-Head Attention ，提升模型理解深度，GPT-3 有 $96$ 个 Head，$1$ 个 Head 负责 $12288/96 = 128$ dim 子空间。
多头注意力的好处是：不同 head 可以从不同角度建模 token 之间的关系。 比如有些 head 可能关注主谓关系，有些 head 可能关注修饰关系，有些 head 可能关注标点、位置或格式。

单个Head里面，$Q \in [3,128]$, $K \in [3,128]$, $V \in [3,128]$
计算每个子空间的 $\text{Attention}_i \in [3,128]$ , $96$ 个头拼起来就是 $\text{Attention} \in [3,12288]$

Output Projection#

我们把 96 个头算出来的 $[3, 128]$ 重新拼接（Concat）回了 $[3, 12288]$。 但是，这 96 个头在计算时是各自独立、互不关心的（Head 0 根本不知道 Head 1 算出了什么。
如果直接把这个拼接结果送给下游，模型就失去了“让不同头的信息发生化学反应”的机会。
因此，多头机制的最后一步，是让拼接后的矩阵强行通过一个输出投影层（Output Projection）：

# 同样是一个 12288x12288 的超大矩阵，参数量约 1.51 亿
self.W_o = nn.Linear(12288, 12288, bias=False)
$$O = \text{Concat}(\text{head}_1,\ldots,\text{head}_{96}) \times \mathbf{W}_o$$

Residual Connection & LayerNorm#

在走完 Output Projection 拿到 $[3, 12288]$ 的新矩阵后，数据并不能直接送进 FFN，必须经历大模型的“复活甲”与“规范化”处理。

GPT-3 采用的是经典的 Pre-LN（前置层归一化） 架构。在每一层内部，数据流遵循“先归一化，再进子模块，最后残差相加”的铁律。

  • LayerNorm： 大模型极其深（GPT-3 共 96 层）。为了防止数据在矩阵乘法中数值越滚越大导致梯度爆炸，在进入 Self-Attention 和 FFN 之前，都要执行 LayerNorm，将一维向量的均值限制为 0，方差限制为 1。

  • Residual Connection ： 为了防止网络太深导致信息在纵向传递时面目全非，引入残差连接。它将进入模块前的原始输入 直接跨越式地硬加（Element-wise Add）到模块的输出上。

    $$X' = X + \text{MHA}(\text{LN}(X)) = X+O$$

FFN / MLP#

走完 Attention 之后，Token 之间已经完成了一轮信息交换。

但这还不够，因为 Attention 更像是在回答“我应该从哪些 Token 里拿信息”，而 FFN / MLP 负责对每个 Token 自己的表示进行更复杂的非线性加工。

GPT-3 的 FFN 可以粗略理解成两层线性层，中间接一个激活函数。

# 中间维度通常是 hidden size 的 4 倍
self.fc_in = nn.Linear(12288, 49152)
self.fc_out = nn.Linear(49152, 12288)
$$\text{MLP}(X') = \mathbf{W}_2 \cdot \text{GELU}(\mathbf{W}_1 X')$$

这里的重点是：

  • Attention 负责 Token 和 Token 之间的信息交互
  • FFN / MLP 负责 每个 Token 内部特征的非线性变换 FFN 这半部分同样要走 Pre-LN 和残差：
$$Y = X' + \text{MLP}(\text{LN}(X'))$$

96 层堆叠#

$$Y_1 = \text{Transform Block}(X)$$

$$Y_{96} = \text{Transform Block}(Y_{95})$$

最后一个Block后，还有一层LN

$$H_{\text{final}} = \text{LN}(Y_{96})$$

预测 Token#

到了这里，GPT-3 还没有真正输出文字。 前面所有计算只是得到每个位置的最终隐藏向量 $H_{\text{final}}$，接下来还需要把隐藏向量映射回词表空间。

$$\text{logits} = H_{\text{final}} \times \mathbf{W}_{vocab}$$

其中：

$$\mathbf{W}_{vocab} \in [12288,50257]$$

所以：

$$[3,12288] \times [12288,50257] = [3,50257]$$

这里的 $[3,50257]$ 表示：每个位置都会对词表里的 $50257$ 个 Token 给出一个分数。 然后对 logits 做 Softmax：

$$P(\text{next token}) = \text{softmax}(\text{logits})$$

GPT-3 根据这个概率分布选择下一个 Token。 比如给定前文：

The capital of France is

模型最后会在词表空间里给所有 Token 打分，其中 " Paris" 的概率可能最高。

小结#

GPT-3 的一次前向传播顺序是：

Token IDs
-> Token Embedding
-> Position Embedding
-> X = E + P
-> 96 层 Transformer Decoder Blocks
-> LN
-> Masked Multi-Head Self-Attention
-> Residual
-> LN
-> FFN / MLP
-> Residual
-> Final LayerNorm
-> LM Head
-> Softmax
-> 下一个 Token 概率分布
